# SLASH

専門学校 2 年次のグループ制作作品。C++ / DirectX 11 で制作した 2D アクションゲームです。
マウスで攻撃方向を決め、チャージダッシュと斬撃をつなぎながらステージを進みます。

## 担当

- ゲームプログラム
- ボスのスキル循環と状態遷移
- ゲーム内容の実装

## 主な実装

- ボスの待機、蓄力、突進、斬撃、ダウン、復帰を状態とタイマーで管理
- アニメーションの指定フレームに合わせた攻撃判定と扇形弾幕
- マップデータからの敵配置、シーン管理、入力処理、描画、サウンド

## ビルド

Windows 10 / 11 64-bit、Visual Studio 2022 以降の「C++ によるデスクトップ開発」、
Windows 10 / 11 SDK、および C++ ATL を使用します。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

インストール済みの Visual Studio を検出して Release / x64 をビルドし、
`build/SLASH` に実行ファイル、シェーダー、ゲーム素材をまとめます。
出力フォルダーの `SLASH.exe` を起動してください。
Visual Studio から編集する場合は `DX21_05_Init.sln` を開いてください。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | A / D または ← / → |
| ジャンプ | Space または W |
| 攻撃方向 | マウスカーソル |
| チャージ / ダッシュ斬撃 | 左ボタンを長押し / 離す |
| チャージ解除 | 右ボタン |
| 足場を降りる | S または ↓ |
| 一時停止 / 再開 | Esc または P |

詳細は `PLAYING.txt` を参照してください。

## 構成

- `DX21_05_Init/` — C++ ソース、ヘッダー、HLSL シェーダー
- `DX21_05_Init/asset/` — 画像、音声などのゲーム素材
